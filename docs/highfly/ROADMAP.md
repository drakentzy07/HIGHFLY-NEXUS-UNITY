# HIGHFLY NEXUS — initial roadmap

## Stage 0 — Foundation
- Import and preserve upstream Unity project.
- Audit dependencies/assets.
- Establish Android CI.

## Stage 1 — Combat Lab
- Third-person mobile controller.
- Left joystick / right camera zone.
- Combo, heavy, dash, dodge, block/parry.
- Smart target acquisition and target switching.
- Cleave, cone and AoE hit queries.
- Enemy/miniboss combat loop.

## Stage 2 — HIGHFLY RPG
- Classes, weapons and skill kits.
- Gates, tower, loot and inventory.
- Fitness training -> persistent character stats.

## Stage 3 — World/MMO
- HIGHFLY city and functional buildings.
- Party/guild/social systems.
- Server/network layer introduced incrementally.
